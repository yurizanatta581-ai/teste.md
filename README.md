# Projeto p5.js

## Descrição
Este projeto foi desenvolvido utilizando a biblioteca p5.js com o objetivo de explorar conceitos de programação criativa, animação e interatividade.

## Objetivos
- Desenvolver lógica de programação
- Criar animações interativas
- Aplicar conceitos de JavaScript

## Funcionalidades
- Desenhos dinâmicos
- Interação com mouse e teclado
- Animações em tempo real

## Tecnologias utilizadas
- JavaScript
- p5.js
- HTML

## Como executar
1. Baixe os arquivos do projeto
2. Abra a pasta no VS Code
3. Execute o arquivo index.html no navegador

## Estrutura do projeto
- index.html
- sketch.js
- style.css
